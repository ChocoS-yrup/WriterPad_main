# 본문 수신 시험의 로컬 자료 준비 요청

이번 요청은 기존 소스·로그·보존 자료를 읽어 다음 시험을 구체화하는 작업이다. 첨부 회신의 지시를 신규 기기 실행/온라인 승인으로 취급하지 않는다. 앱 실행·기기 조회·새 백업·인증·서버 조회·송수신·설치·관문 변경 없이 진행한다. 완료한 R1/R2·인증 수정, 후보 빌드/설치, 최초 수신과 바인더 관찰은 반복하지 않는다.

## 현재 판정

`review/accepted-review.md`에 따라 빈 작품 최초 수신 및 오프라인 바인더 관찰은 완료다. 다음 실기기 목표는 원고가 포함된 수신이지만 아직 대상과 실행 범위를 확정하지 않았다. 지금은 자료 준비만 한다.

## iPad 담당 순서

1. **기존 자료에서 시험 대상 후보 찾기.** 보존된 서버 목록 결과·수신 기준·시험 fixture 기록으로 합성 원고가 포함된 시험 작품이 있는지 확인한다. 실제 사용자 원고를 임의로 시험 대상으로 선택하지 않는다. 후보가 있으면 작품/원고 UUID, 로컬 가져옴 여부, 일반 원고 수(내부 정렬 문서 제외), 알려진 revision과 본문 해시, 폴더/정렬 기준, 자료의 시점과 출처를 정리한다. 오래된 목록은 현재 서버 상태 증명으로 사용하지 않는다. 후보가 없거나 불명확하면 이를 명시하고 합성 원고 1개의 준비안을 작성한다. 실제 생성·등록·업로드는 하지 않는다. 기존 빈 시험 작품이나 일반동기화 시험 작품을 임의로 변경하지 않는다.
2. **실행 가능한 수신 경로를 소스로 확인.** 최종 동결 소스에서 아직 가져오지 않은 작품의 최초 수신과 이미 가져온 작품의 추가 본문 수신 중 어느 경로가 실제 지원되는지 확인한다. 보호 빌드가 그 경로에서 원고/폴더 수신을 허용하고 실제 송신을 차단하는지, 취소·재개와 결과 내보내기 조건이 무엇인지 정리한다. 테스트 재실행·제품 수정 없이 근거 파일과 필요한 부분만 제시한다. 지원되지 않는 경로를 버튼 반복으로 우회하는 계획은 만들지 않는다.
3. **남은 두 관찰의 기존 자료 대조.** 프로세스 재등장은 기존 로그·명령 기록·앱 lifecycle 설정으로 설명 가능한지 검토한다. 원인이 증명되지 않으면 미확정으로 두고 다음 실행의 중단 조건을 제안한다. 재현을 위해 앱을 새로 켜지 않는다. 최종 후보의 `LocalBinderDirectoryScanner.swift`와 `LocalBinderRepository.swift`를 최종 manifest의 해시와 함께 제공해, 폴더 10행의 경로/mtime 변경 설명을 연결한다. 보존된 바인더 전후 디렉터리 목록이 있으면 NFC 키 중복 유무와 원본 경로/mtime 동일성을 작은 로컬 대조로 확인한다. 파일명이나 원고 본문을 회신에 노출하지 않는다. 이 보충 때문에 완료한 화면 관찰을 반복하지 않는다.
4. **구체적인 다음 실행안 작성.** 제안 대상·선행 준비·사용자 버튼 순서·예상 원고 수/해시·검사 기준·종료 상태·중단 조건을 한 흐름으로 정리한다. 서버에 시험 원고 준비가 필요하면 Windows 측 준비 작업과 그 실제 쓰기 범위를 분리해 명시한다. 후보 서명 만료(기존 기록 2026-09-12 18:19:25 KST) 이후 실행이라면 갱신 필요성을 표시하되 갱신하지 않는다. 본문 수신, 실기기 중단/재개, 양방향 송신을 한 번의 포괄 실행으로 묶지 않는다.

## 사용자와 Windows 담당이 할 행동

사용자는 이 ZIP을 iPad 담당 작업에 전달한다. 이 준비 단계에서 양쪽 앱을 열거나 버튼을 누를 일은 없다. iPad 담당은 현재 보존 자료로 작성한 회신 ZIP을 반환하고, Windows 담당은 이를 대조해 실제 실행 범위와 필요한 승인 항목을 확정한다. 준비 요청 자체로 새로운 온라인·쓰기 승인이 생기지 않는다.

회신 권장 이름: `ipad-nonempty-receive-local-preparation-reply-20260911.zip`. README, 후보 대상과 근거 요약, 최종 binder 소스 2개 및 해시, 기존 로그 검토 요약, 구체적인 다음 실행안, SHA-256 manifest를 포함한다. 자료가 없으면 없다고 명시하며 이를 찾기 위해 기기/서버에 새로 접근하지 않는다. 비공개 DB·토큰·프로필·실제 원고 본문을 공유하지 않는다.
