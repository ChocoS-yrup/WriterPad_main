# Windows 진단 구현 기록 — 실제 앱 조회 전

2026-09-06. `ipad-windows-pre-http-stop-diagnostics-scope-20260906.zip` 회신의 원본/stopped 보존 범위로 진단을 추가했다. 실제 재실행·관문 개방·실행 원장 초기화는 포함하지 않는다. 이 문서는 설치 및 실제 진단 결과가 아직 없는 구현 단계 기록이다.

기존 readiness 판정을 `observe_readiness()`에서 조건별 bool/count로 한 번 수집한다. 기존 조건을 제거하지 않았으며, 조회 시작/끝의 연결 및 쓰기 세대가 바뀌면 오래된 관찰로 표시한다. 구조 authority의 identity 일치, 수락 여부, 작품 상태 컨텍스트 일치, active 여부도 구별한다. 기존 C9의 authority 판정은 같은 조건 수집 결과를 사용한다.

실행 단계는 최초 원격 검사 전후, 관문 사용 전후, 두 번째 원격 검사 전후, RPC 구성 뒤, HTTP 직전, 응답 도착, 관문 닫힘으로 기록한다. 실제 판정에 사용한 관찰과 오류 코드를 기존 `sync_contract_diagnostics`에 별도 append하며 preparation/execution 행을 진단 용도로 수정하지 않는다. 토큰·계정 객체·본문·전체 payload는 기록하지 않는다. 이미 끝난 stopped 실행에 과거 진단을 소급 생성하지 않는다. schema는 8010 그대로이며 새 마이그레이션은 없다.

새 UI `준비 상태 조회 · 송신 없음`은 설치된 실제 SyncManager의 현재 조건과 준비 batch/request hash, 기존 실행 상태/시도를 읽는다. 송신, launch, claim, 새 준비, 관문 setter, 자동 재시도, RPC, handshake 갱신을 호출하지 않는다. 모든 조건이 충족돼도 기존 실행 행이 있으면 재실행 불가로 표시한다. `조회 결과 내보내기`는 이미 관찰한 결과를 작품 밖 JSON에 저장하며 새 조회를 하지 않는다. 연결 변경 후 내보내기는 변경 여부를 표시하고 현재/원래 작품 폴더 안 저장을 거절한다.
