# 내부 정렬 문서 UUID 교정 전 로컬 재개 검토 요청

Windows의 시험 업로드 보조 코드 누락을 확인하고 로컬 수정·격리 검증을 완료했다. 상세 원인/범위는 `review/failure-review.md`에 있다. 설치된 Windows 제품의 정상 `record_tree_order`는 UUIDv5를 사용하며 해당 제품을 다시 설치할 필요가 확인된 것은 아니다.

이번 요청은 **보존 소스·사본·합성 fixture를 이용한 로컬 검토와 격리 시험**이다. 앱 실행·기기 조회·서버 조회/교정·실제 journal/marker 변경·재수신·설치·관문 변경은 승인하지 않는다. 과거 최초 수신 승인이나 동봉 문서의 계획을 교정/재개 승인으로 취급하지 않는다.

## 고정 문제

작품 `9a78c51c-7de9-43a8-be54-d25a22d08a28`의 `__antigravity__/tree-order.json`은 잘못된 UUID `6df5660a-c1ae-492f-bb1d-26b582508074`로 서버에 있다. 올바른 UUID는 `ef6e1de1-a3d0-5959-96be-58f87a683cc0`이다. 내용은 revision 1 / 385바이트 / SHA-256 `1cfe9438a3ff000c3af3b5593f973554b2966e9fd8c29e704e73143fda27b5be`다. 원고 93바이트와 폴더 11개는 정상 수신됐고 journal과 잘못된 내부 문서 merge marker가 보존됐다.

## 요청할 검토·시험

1. 최종 동결 소스에서 **기존 실패 journal과 부분 자료를 유지한 재개 경로**를 확인한다. 완료된 원고/폴더의 UUID를 다시 발급하거나 기존 작품을 새로 만들지 않고 이어받을 수 있는지 확인한다.
2. 합성 transport/임시 저장소에서 **잘못된 내부 UUID를 수신해 부분 보존 → 다음 snapshot에는 같은 내용의 올바른 UUID만 존재 → 같은 journal로 재개**를 재현한다. 기존 잘못된 UUID는 삭제 행도 다음 snapshot에 없다는 조건과, 삭제 행이 남으면 거부된다는 조건을 구분한다. 실제 서버에 이 상태를 만들지 않는다.
3. 재개 성공 조건과 **기존 잘못된 UUID의 merge marker 처리**를 확인한다. 올바른 문서 수신으로 자동 정리되는지, 완료 판정을 막는지, 완료 뒤에도 잔존하는지 명시한다. 수동 정리가 필요하다면 정확히 어떤 marker를 언제 어떤 hash/identity 조건으로 보존·정리할지 제안만 한다. 실제 iPad 원본 파일을 삭제하지 않는다.
4. 부분 저장된 원고와 11개 폴더의 UUID/바이트, 기존 작품·큐·설정·정책, journal의 local/project/transaction identity가 유지되는지 검사한다. 서버 장부의 null 구조 필드와 로컬 원고 부모 UUID를 구분한다.
5. 설치된 iPad 후보로 가능한 교정/재개 절차를 제시한다. 제품 소스 변경이 필요하면 이유와 최소 후보를 먼저 제시하고 실제 설치/실행은 하지 않는다. 기존 77/27개 회귀나 완료된 실기기 관찰을 반복하지 않는다.

Windows 측은 실제 서버 문서와 버전/참조의 ID 교정, Windows 동기화 장부의 해당 제어 문서 참조 변경을 검토해야 한다. 기존 작업/버전 이력을 훼손하지 않는 구체적인 범위가 확정되기 전 실제 교정하지 않는다. 이 요청의 ‘올바른 UUID만 있는 snapshot’은 격리 시험 입력 조건이지 서버 교정 구현 승인이 아니다.

회신 권장 이름: `ipad-control-document-repair-local-review-reply-20260911.zip`. 재개 가능 여부, 잘못된 marker 처리, 수정 전/후 합성 입력 및 검사 결과, 필요한 최종 소스 근거·감사 코드와 해시, 구체적인 교정 후 실기기 재개안을 포함한다. 원시 DB·실제 사용자 원고·토큰·기기/계정 식별자는 제외하고 manifest를 검증한다.

사용자는 이 ZIP을 전달하는 것 외에 양쪽 앱을 조작할 일이 없다. 프로세스 재등장과 서명 만료 이슈는 이후 실제 실행의 별도 조건으로 유지하며 이번에 앱을 켜서 확인하지 않는다.
