## 향후 승인할 구체적인 Windows 설치 범위 — 현재 미실행

1. 설치 직전 앱 종료·기존 EXE/후보 해시·원본/백업 동일성을 확인한다. 현재 백업 이후 변경이 있으면 새 일관된 사본을 확보한다.
2. 설치 대상 `D:\안티그래비티\scratch\집필프로그램\작가님 힘내세요.exe` 하나를 검증한 후보로 교체하고, 새 후보 ID/해시를 기록하는 별도 설치 정보 파일만 추가한다. 기존 독립 복구 도구는 동일하므로 재설치하지 않는다.
3. 다른 설치 파일·원고·identity·설정·실제 AppData/DB·관문·송신 보류가 그대로인지 대조한다. DB 8012→8013 업그레이드나 이전 UUID 한 항목 교정을 반복하지 않는다.
4. 설치 뒤 앱 일반 실행은 별도 단계다. 후보를 직접 더블클릭하여 실제 프로필로 실행하지 않는다. 설치만으로 로그인·수신·자동 등록·송신을 허용한 것으로 취급하지 않는다.
5. 설치만 끝난 상태에서 복구가 필요하면 앱 종료 및 데이터 불변을 확인하고 검증한 이전 EXE를 복원할 수 있다. 첫 실행이나 서버 통신 뒤 변경이 생겼다면 해당 자료부터 보존하고 재대조하며 DB를 통째로 덮어쓰지 않는다.
