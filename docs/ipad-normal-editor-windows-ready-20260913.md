# Windows 병행 구현 결과

공통 기준 `normal-editor-single-document-20260913-v1` 일치 회신과 receipt 인터페이스를 반영했습니다.

- Windows 일반 집필 UI의 자유 본문·Ctrl+S·800ms 유휴 저장, 인증과 로컬 저장 분리, 초안 재시작 보존, 명시적 송수신·복구 연결을 구현했습니다.
- 격리 검사 **31개 통과 / 실패 0**. 실제 socket 연결 금지, 복제 저장소·모의 HTTP 사용입니다.
- receipt는 전달받은 `sync_batches` → `sync_batch_results`의 제한 SELECT 두 번과 count/계정/요청/응답 해시 검증을 사용합니다. 조회를 위해 document_commit을 다시 호출하지 않습니다. 부재·불일치는 미확정 상태를 유지합니다.
- 한 번에 불변 operation 하나만 전송 대상으로 삼고 후속 편집은 별도로 보존합니다. 충돌은 기준/로컬/원격 보존 후 중지하며 자동 취소/덮어쓰기를 하지 않습니다. 준비 만료와 로컬 저장·완료 표시를 분리했습니다.
- 후보 EXE 빌드·설치·실제 서버 조회/송수신·설정 변경은 아직 하지 않았습니다. 기존 revision 6 완료 결과를 보존하며 prod 전환은 없습니다.

iPad 병행 구현이 끝나면 **검사 결과와 남은 차이/차단만** 전달해 주세요. 공통 기준이나 완료된 왕복 검증은 다시 검토할 필요가 없습니다. 양측 후보·실행 범위 준비 후 설치·실기기 단계로 진행합니다.
