## 실행 시 핵심 조건

1. 마지막 종료 시점 자료와 기존 사후 백업의 동일성을 확인하고 변경됐으면 새 일관된 백업을 확보한다. 원본 DB는 SQLite로 열지 않고 검사 사본을 쓴다.
2. 사용자에게 비행기 모드, Wi-Fi/셀룰러 끄기, 유선 개발 연결 유지 행동을 안내한다. USB/이더넷/인터넷 공유 등 대체 인터넷 경로도 확인해 앱 실행 전부터 종료 후 대조까지 외부 통신 차단을 유지한다. 준비가 확인되지 않으면 실행하지 않는다.
3. 개발 도구로 정확한 bundle을 한 번 실행하고 `-writerpad.sync-all-projects-enabled NO -writerpad.restore-last-project-on-launch NO`를 전달한다. 명령과 런타임에서 인자 전달·실효값을 확인한다. 영구 저장 설정은 바꾸지 않는다. 자동 동기화 제한 인자만으로 네트워크 차단이 됐다고 간주하지 않는다.
4. 사용자는 로컬 작품 목록이 보이는지와 오류 유무만 알려 준다. 작품 선택·편집·생성·삭제, 로그인·서버 목록·동기화 버튼은 조작하지 않는다. 마지막 작품이 자동으로 열리거나 제한 적용이 확인되지 않으면 조작을 멈추고 기록한다. 오류가 나도 반복 실행하지 않는다.
5. 앱 종료와 프로세스 부재를 확인하고, 네트워크 차단 상태에서 원고·binding·DB 보호 대상 행·큐·충돌·journal·관문·전역 영구 설정을 전후 비교한다. 정상 초기화 메타데이터/캐시와 보호 대상 자료 차이를 구별한다. 문제가 있으면 현재 자료부터 보존하고 자동 롤백이나 DB 덮어쓰기를 하지 않는다.

iPad 저장값은 전역 동기화 true / 시험 관문 true, pending 4 / conflict 3 / journal 0이 마지막 관측이다. 전역 설정과 관문이 닫혀 있다고 표현하지 않는다. 이번 제한 인자는 해당 실행에만 적용되므로 이후 일반 아이콘 실행도 허용됐다고 보지 않는다. 기존 미완료 큐나 충돌을 처리하지 않는다.
