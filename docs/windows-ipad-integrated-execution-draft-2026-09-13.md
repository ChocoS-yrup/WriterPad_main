## 최소 통합 흐름 제안

1. **양측 설치·오프라인 준비:** 실행안 확정·사용자 승인 후 설치한다. 새 시험 ID의 초기화 방법과 승인 범위 연결까지 준비하며, 여기서 임의 송수신하지 않는다.
2. **Windows → iPad:** Windows가 시험 루트·A/B·두 문서를 만들고 저장·문서 전환·자동 송신을 묶어 확인한다. iPad가 같은 ID로 수신한다.
3. **iPad → Windows:** iPad가 본문 편집, 폴더 이름 변경·문서 이동·정렬, 내용 있는 폴더 삭제·복원을 묶어 수행하고 Windows가 수신한다. 빈 본문 처리도 함께 대조한다.
4. **양측 복구·충돌:** 원래 batch의 응답 유실 복구와 중단/복귀를 확인한다. 마지막에는 시험 문서에만 동시 편집 충돌을 만들어 기준·로컬·원격을 보존한다. 계획된 장애가 예상 상태라면 복구까지 이어간다. 정확한 주입 위치·횟수·복구 버튼/동작은 후보 기능과 대조해 확정한다.
5. **동시 종료:** 자동 실행을 중지하고 합의된 최종 본문·구조, 의도적으로 남긴 충돌, 설명되지 않는 미완료 작업 없음, 임시 변경 복원을 확인한다. 시험 자료를 서버에서 정리 삭제하는 요청은 추가하지 않는다.
