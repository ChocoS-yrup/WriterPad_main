# Windows S2 수신 완료 — iPad S3 진행 신호

Windows 수신 1회 후 종료된 저장소 복제본·TXT를 대조했습니다. **R=45바이트/rev4/srev4, E=0바이트/rev4/srev6**, `T=[A수정,B]`, `A수정=[]`, `B=[E,R]`, 정렬 T2/A7/B5가 iPad 보고와 일치합니다. 대기·충돌 0, 자동 꺼짐, 앱 종료입니다. 기존 보호 파일·원래 완료 작업 19개·감사 기록을 보존했습니다. iPad S2 추가 저장/빈 자동 초과 기록은 그대로 유지하며 준수 통과로 바꾸지 않습니다.

사용자가 계획 초과 기록을 보존한 **수동 후속 진행을 승인**했습니다. 같은 실행 ID·15:00 KST 만료·기존 한도/누적 사용량을 유지하고, 양측 자동은 계속 끕니다.

**iPad 다음은 기존 S3 두 동작입니다.**

1. **E(빈문서.txt)만 삭제하고 수동 송신 완료를 확인합니다.**
2. 이어서 **B 폴더를 삭제하고 수동 송신 완료를 확인합니다.**

두 삭제를 한꺼번에 모아 보내지 않습니다. E는 먼저 별도 삭제하고, 이후 B와 R이 함께 삭제되는 구분을 보존합니다. 완료 후 대상 미완료 batch/작업 여부와 누적 HTTP/Auth/쓰기를 회신하고 대기해 주세요. **Windows가 B/R/E 삭제 상태를 수신·확인하기 전에는 S4 복원하지 않습니다.**

S3 계획 쓰기는 기존 **5회**, 수동 송수신 **2회**입니다. 이 문서는 기존 승인 범위의 다음 단계 신호이며 자동 주기·한도 증액·추가 작업을 허용하지 않습니다. Windows 현재 사용량은 **HTTP 182/280·Auth 25/30·쓰기 19/21**입니다. Windows 토큰은 **14:08:18 KST**까지 유효하므로 지연 시 후속 실행 전 유효성과 남은 Auth 한도를 함께 확인합니다.
