요구사항:

수동 저장(Ctrl+S)은 '메인' 폴더에, 5초 디바운스 오토세이브는 '백업' 폴더에 저장되도록 분리해.

ProjectManager에서 동일한 파일에 동시 접근하는 것을 막기 위해 동시성 제어(QMutex 등)를 적용해.

[매우 중요] 오토세이브 실행 시, 백그라운드 스레드(FileSaveWorker)가 GUI 위젯의 .toPlainText()를 직접 호출하면 PyQt6가 크래시(Crash)되니까 절대 금지야. 반드시 메인 스레드에서 5초 디바운스 타이머가 돌고, 타이머 만료 시 메인 스레드에서 텍스트를 String으로 추출한 뒤, 그 문자열 데이터만 FileSaveWorker에 넘겨서 비동기로 파일 I/O가 처리되게 구조를 짜줘.

4단계: 비동기 처리 및 3단계 요약 워크플로우 (핵심)
#복사시작#
마지막으로 텍스트 기반 워크플로우 중 가장 중요한 '3단계 화수별 요약 로직'과 '비동기 처리'를 구현할 거야.

요구사항:

API 통신 시 메인 윈도우가 하얗게 '응답 없음' 상태가 되지 않도록, 가벼운 API 호출이든 무거운 요약 작업이든 무조건 별도의 QThread 워커를 통해 비동기로 실행시켜. 작업 도중에도 유저는 화면에서 글을 쓸 수 있어야 해. 상태와 결과는 pyqtSignal로 UI에 전달해.

기획서에 명시된 요약 탭 3단계 자동화 분기를 정확히 구현해.

[1구간: 1~25화] 완성본 확정 시, API 호출 없이 원문을 요약 폴더에 복사/저장.

[2구간: 26화 최초 대규모 요약] 26화 확정 시 모달을 띄우고, 1~21화 원문을 5화 단위 백그라운드 분할 요약 진행. 컨텍스트 캐싱을 사용하고, 유저 피드백(멀티턴) 과정을 거친 후, 조율된 '1~21화 요약본' + '22~26화 원문'을 병합해 최종 26화 요약 파일 생성.

[3구간: 27화 이상 롤링 업데이트] 이전 결과물(1~N화 요약본 + 원문)을 바탕으로 새 요약본을 만들고, 거기에 최근 원문 5개를 덧붙여 결합하는 가벼운 구조로 구현해.
